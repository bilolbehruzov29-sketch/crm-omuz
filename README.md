# CRM Omuz Bilol: монеты и журнал для учебного центра

Учебная CRM на Django (MVT). В ней три роли: **администратор**, **учитель** и **ученик**.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows   (Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo      # демо-данные (необязательно)
python manage.py runserver
```

Сайт откроется по адресу http://127.0.0.1:8000.

Демо-аккаунты (созданы командой `seed_demo`):

| Роль    | Телефон   | Пароль     |
|---------|-----------|------------|
| Админ   | 900000001 | admin123   |
| Учитель | 900000002 | teacher123 |
| Учитель 2 | 900000003 | teacher123 |
| Ученик  | 900000010 | student123 |

## Что умеет каждая роль

**Ученик**
- **Профиль:** личные данные, группы, посещаемость за месяц (был, пропустил, опоздал, %), расписание, оценки по дням.
- **Журнал группы:** график недельных баллов всех учеников и таблицы по каждой неделе.
- **Награды:** кошелёк монет, история начислений, «мои обмены», каталог призов с поиском и фильтром по цене, обмен монет на приз.

**Учитель**
- Видит только свои группы и своих учеников.
- **Журнал:** ставит присутствие (✅ / ⏰ / ❌), оценку 0–5, бонусные баллы за занятие, экзамен недели (0–100) и бонус за неделю.
- Кнопка **«Сохранить и закрыть неделю»** считает недельный балл и сама начисляет монеты.
- **«Дать монеты»:** может начислить ученику любое количество монет с причиной.

**Администратор**
- **Обзор:** счётчики, активные группы, лидеры по монетам, последние операции.
- Видит **все группы, всех учителей, всех учеников**: создаёт, редактирует, **удаляет**.
- **Страница группы:** добавить учеников (выбор из списка с поиском), убрать ученика из группы, назначить или снять учителя, создать нового ученика сразу в эту группу.
- **Блокировка:** закрывает ученику или учителю вход, данные при этом сохраняются.
- **Курсы и филиалы:** добавить, переименовать, удалить. Курс, в котором есть группы, удалить нельзя.
- Каждое удаление спрашивает подтверждение в отдельном окне.
- Управляет каталогом наград и подтверждает заявки на обмен. При отклонении монеты возвращаются ученику.
- Видит историю всех операций с монетами. Может начислять и списывать монеты.
- Есть стандартная Django-админка: `/django-admin/`.

## Правила монет

Недельный балл считается от 0 до 100:
1. Процент за занятия: сумма оценок / (5 × число прошедших занятий) × 100. Пропуск занятия даёт 0.
2. Если поставлен экзамен недели, балл = 70% занятия + 30% экзамен.
3. К результату прибавляются бонусные баллы (за занятия и за неделю), итог ограничен 100.

| Недельный балл | Монеты |
|----------------|--------|
| больше 95      | **5** («Отличный балл недели») |
| больше 90      | **3** («Хороший балл недели»)  |

Плюс учитель может в любой момент дать сколько угодно монет вручную.

Пороги задаются в `config/settings.py`, параметр `WEEKLY_COIN_RULES`.

Повторно закрывать неделю безопасно: начисляется только разница. Если учитель исправит оценки в уже закрытой неделе, монеты пересчитаются автоматически: добавятся или спишутся.

Прошедшие недели можно закрывать автоматически, например по cron каждое воскресенье:
```bash
python manage.py close_weeks
```

## Дизайн
- Тёмная боковая панель, градиенты, иконки [Lucide](https://lucide.dev) (лицензия ISC).
- Светлая и тёмная тема: кнопка 🌙 вверху, выбор запоминается.
- Адаптивная вёрстка: на телефоне меню открывается кнопкой ☰.
- Всплывающие уведомления и окна подтверждения вместо стандартных `confirm()`.
- Шрифт Manrope (Google Fonts). Chart.js лежит в проекте, поэтому график работает без интернета.

## Структура
- `core/models.py`: пользователи (вход по телефону), филиалы, курсы, группы, журнал, итоги недель, монеты, награды, обмены.
- `core/services.py`: подсчёт недельного балла, начисление монет, обмен наград.
- `core/views.py`, `core/urls.py`: страницы.
- `core/permissions.py`: кто что видит.
- `core/templates/core/`: HTML-шаблоны.
- `core/templatetags/ui.py`: иконки и аватарки для шаблонов.
- `core/static/core/`: стили (`app.css`), скрипт интерфейса (`app.js`), Chart.js.
